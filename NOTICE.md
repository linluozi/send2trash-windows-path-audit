What was changed
----------------
Only the Windows path handling. ``send2trash/plat_other.py``,
``send2trash/plat_gio.py``, ``send2trash/mac/*``, ``send2trash/win/__init__.py``
and ``send2trash/win/IFileOperationProgressSink.py`` are byte-for-byte
identical to the baseline.

Modified files
~~~~~~~~~~~~~~
``send2trash/util.py``
    Added ``normalize_win32_path()`` and its ``\\?\`` translation helper.
    ``preprocess_paths()`` is unchanged.

``send2trash/win/legacy.py``
    ``send2trash()`` calls ``normalize_win32_path()`` instead of decoding
    bytes with ``mbcs`` and conditionally calling ``abspath``. The now-unused
    ``os.path as op`` import was removed.

``send2trash/win/modern.py``
    ``send2trash()`` calls ``normalize_win32_path()`` instead of the naive
    ``path[4:]`` prefix strip, and pairs ``CoInitialize`` with exactly one
    ``CoUninitialize``. The COM body moved into ``_delete_items()``, whose
    ``com_error`` conversion now also covers ``CoCreateInstance`` and
    ``SetOperationFlags``.

Added files
~~~~~~~~~~~
``tests/test_win_path_handling.py``
    61 regression cases over both Windows backends, driven against real files.

``README.rst``, ``CHANGES.rst``
    Documentation of the new path handling.

Files added for this audit only, not part of the patch
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
``NOTICE.md`` (this file), ``AUDIT_REPORT.md``, ``README.md``, ``index.html``,
``audit/``, ``bench/``, ``docs/assets/``.

The figures in ``docs/assets/`` are generated by ``bench/make_figures.py`` and the
report page by ``bench/make_page.py``; both read their numbers from the raw run
output in ``audit/``. ``bench/verify_page.py`` renders ``index.html`` in headless
Chromium and asserts the images decoded and nothing overflows.
